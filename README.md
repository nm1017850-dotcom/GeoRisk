# GeoRisk AI

Қазақстандағы көшкін қаупін талдауға арналған геокеңістіктік жұмыс ортасы. Интерфейс қазақ тілінде. Бағалау нәтижелері мен ескертулер жергілікті SQLite дерекқорында сақталады.

**Маңызды:** бағалау төтенше жағдай туралы ресми ескерту немесе инженерлік қорытынды емес. Оқытылған модель мен тексерілген деректер жоқ кезде нақты болжам жасалмайды. Демонстрациялық деректер нақты бағалаудан бөлек белгіленуі тиіс. Сыртқы жауын-шашын, жер бедері және геология деректері автоматты түрде бар деп есептелмейді.

## Қажетті құралдар

- Python 3.10 немесе одан жаңа нұсқа
- Node.js 20 немесе одан жаңа нұсқа және npm
- Chrome немесе басқа заманауи браузер

## Linux / macOS: іске қосу

Бірінші терминалда серверді іске қосыңыз:

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

Екінші терминалда интерфейсті іске қосыңыз:

```bash
cd frontend
npm install
npm run dev
```

Vite көрсеткен жергілікті мекенжайды Chrome браузерінде ашыңыз. Әзірлеу сервері `/api` сұрауларын 8000-порттағы серверге бағыттайды. Сервер күйін `/api/health` арқылы тексеруге болады.

## Windows 11 (PowerShell)

Репозиторий түбірінде бірінші PowerShell терезесін ашыңыз:

```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8000
```

Екінші PowerShell терезесінде:

```powershell
cd frontend
npm install
npm run dev
```

Терминалда көрсетілген мекенжайды Chrome-да ашыңыз. PowerShell виртуалды ортаны белсендіруге кедергі жасаса, `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` және `.\.venv\Scripts\python.exe -m uvicorn app:app --port 8000` командаларын `backend` бумасында тікелей қолданыңыз.

## Модельді оқыту

Нақты, белгіленген көшкін деректері қажет; олар бұл репозиторийге кірмейді. Деректер сапасы, өлшем бірліктері және дереккөзін маман тексеруі керек. Сервердің виртуалды ортасын белсендіріп, репозиторий түбірінен орындаңыз (Windows: `.\backend\.venv\Scripts\python.exe -m backend.ml.train --data path/to/labeled.csv --output backend/models`):

```bash
backend/.venv/bin/python -m backend.ml.train --data path/to/labeled.csv --output backend/models
```

CSV бағандары: `latitude`, `longitude`, `elevation`, `slope`, `rainfall_accumulation`, `rainfall_intensity`, `soil`, `land_cover`, `fault_distance` (бос болуы мүмкін), `label` (0 немесе 1), `region_id` (географиялық топ). Кемінде үш бөлек аймақ және оқыту, калибрлеу, тест бөліктерінің әрқайсысында екі класс қажет. Жеткіліксіз дерекпен оқыту тоқтайды. Метрикалар мен модель нұсқасын қолданар алдында тексеріңіз; демонстрациялық деректер нақты болжамға жарамайды.

## Көмекші және конфигурация

OpenAI көмекшісі үшін `OPENAI_API_KEY` орталық айнымалысын сервер процесіне орнатыңыз. Кілт браузерге жіберілмеуі және Git-ке қосылмауы керек. `OPENAI_MODEL`, `GEORISK_DB_PATH`, `ALERT_RISK_THRESHOLD` қосымша айнымалыларының үлгілері [.env.example](.env.example) файлында. Үлгі файл орта айнымалыларын өздігінен қоспайды: оларды сервер іске қосылатын терминалда немесе қауіпсіз орта баптауларында орнатыңыз. API кілті болмаса, қалған жергілікті мүмкіндіктерді пайдалана аласыз, ал көмекші қолжетімсіз болады.

Карта тақталары мен сыртқы қызметтерге желі қажет. Дерек көзі қолжетімсіз болса, оның мәндерін ойдан толтыруға болмайды. Жобадағы деректердің шығу тегін және модель шектеулерін кез келген шешім қабылдамас бұрын тексеріңіз.

CSV (`latitude`, `longitude`) немесе GeoJSON Point FeatureCollection жүктеу координаталарын тексереді (5 МБ дейін); күндер, өлшем бірліктері және дереккөздің дұрыстығы автоматты тексерілмейді; жүктеу деректерді модельге автоматты түрде қоспайды. Қауіпті бағалау үшін бөлек, шығу тегі мен белгілері тексерілген оқыту жиынын пайдаланыңыз.

Карта қабаттары `tile.openstreetmap.org` және `server.arcgisonline.com`, ал көмекші `api.openai.com` домендеріне HTTPS қатынасын талап етеді. Шектеулі желіде осы домендерге рұқсат қажет. IMERG, Copernicus DEM және геологиялық GIS деректері бұл жобаға автоматты қосылмаған; қолжетімділігі мен шығу тегін жеке тексеріңіз.

## Хостингке жариялау

`Dockerfile` интерфейс пен API-ді бір контейнерде іске қосады. Контейнер әдепкіде 8080 портын тыңдайды. Хостинг ұсынған портты `PORT` айнымалысы арқылы беруге болады.

```bash
docker build -t georisk-ai .
docker run --rm -p 127.0.0.1:8080:8080 georisk-ai
```

Render-де жаңа Blueprint жасап, осы файлдар сақталған GitHub репозиторийін және тармағын таңдаңыз. `render.yaml` тегін веб-қызметті және `/api/health` күй тексерісін анықтайды. Қызметтің **Environment** бөлімінен жүйе жасаған `GEORISK_SITE_PASSWORD` құпиясөзін алыңыз. Render берген HTTPS мекенжайын ашып, пайдаланушы аты ретінде `georisk` енгізіңіз. Құпиясөзді Git-ке қоспаңыз.

Тегін Render қызметі SQLite дерекқорын тұрақты сақтамайды. Бағалаулар мен ескертулерді сақтау үшін тұрақты диск қолдайтын тариф пен диск қажет. Дискіні контейнердегі қолданушы (`10001`) жаза алатын жерге тіркеп, `GEORISK_DB_PATH` арқылы дерекқордың жолын беріңіз. Нақты болжам үшін осы ортаға үйлесімді, сенімді оқытылған `model.joblib` артефактісін `/app/backend/models/` бумасына орналастырыңыз. OpenAI көмекшісін қосу үшін кілтті хостингтің құпия айнымалысына сақтаңыз.

### Vercel

Vercel-де осы GitHub репозиторийін импорттап, **Root Directory** ретінде `frontend` бумасын таңдаңыз. [vercel.json](frontend/vercel.json) Vite құрастыруын және браузерде тікелей ашылатын интерфейс беттерін баптайды.

Интерфейсті API-сіз де ашуға болады: карта мен навигация жұмыс істейді, сервер күйі қолжетімсіз болып көрсетіледі. Талдау, тарих, есептер мен ескертулер үшін Docker серверін HTTPS арқылы жариялап, Vercel жобасының **Environment Variables** бөлімінде `GEORISK_API_ORIGIN` мәнін орнатыңыз (мысалы, `https://your-georisk-backend.example`). Мәнге `/api` немесе құпиясөзді қоспаңыз. Айнымалыны өзгерткеннен кейін Vercel жобасын қайта жариялаңыз.

Vercel функциясы интерфейстің `/api` сұрауларын FastAPI серверіне бағыттайды. Құпиясөз орнатылған серверге қосылу үшін интерфейстен **Серверге кіру** тармағын ашып, `georisk` пайдаланушы аты мен сервердің құпиясөзін енгізіңіз. SQLite файлы мен оқытылған модель Docker серверінде қалады. Vercel Functions сұрау денесін 4,5 МБ-қа дейін қабылдайды; үлкен файлдарды тікелей Docker серверіне жүктеңіз.

#### Vercel-де OpenAI көмекшісін қосу

FastAPI әлі қосылмаған болса, Vercel функциясы GeoAI көмекшісін жеке іске қоса алады. Vercel жобасының **Settings → Environment Variables** бөлімінде **Production** ортасы үшін `OPENAI_API_KEY` (жаңа OpenAI API кілті) және `GEORISK_ASSISTANT_PASSWORD` (көмекшіге кірудің бөлек құпиясөзі) мәндерін құпия айнымалы ретінде қосыңыз. Қажет болса, `OPENAI_MODEL` айнымалысынан модельді таңдаңыз. Әдепкі модель — `gpt-4o-mini`. Айнымалыларды сақтаған соң **Deployments → Redeploy** таңдаңыз.

«ЖИ болжамы» бетінен көмекшіге сұрақ жіберіңіз. **Көмекшіге кіру** сілтемесін ашып, пайдаланушы аты ретінде `georisk`, құпиясөз ретінде `GEORISK_ASSISTANT_PASSWORD` мәнін енгізіңіз. Vercel-дегі көмекші жалпы геологиялық сұрақтарға қазақша жауап береді. Көшкін қаупін сандық бағалау және сақталған талдауларды пайдалану үшін FastAPI мен оқытылған модель қажет.

Егер `GEORISK_API_ORIGIN` орнатылса, сұраулар FastAPI серверіне жіберіледі. Бұл кезде OpenAI кілті Vercel жобасына емес, FastAPI серверінің құпия айнымалысына енгізіледі.
